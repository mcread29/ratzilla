# tty0

`tty0` is not a shell simulator first. It is a recovered archive interface built around extinction records, corrupted testimony, and music presented as evidence.

This folder contains the example app plus a small set of design docs for the fiction and interface direction.

## Docs

- [CANON.md](./CANON.md): core lore, rules of the setting, and tone constraints
- [EXPERIENCE.md](./EXPERIENCE.md): interface direction, screen flow, and hidden terminal plan
- [TRACKS.md](./TRACKS.md): track naming system, first two records, and reusable metadata structure

## Design stance

- The first version should feel like an artifact browser, not a prompt-driven terminal.
- The filesystem exists in the fiction, but the UI surface is a curated archive workstation organized around the records themselves.
- The terminal should appear later as a restricted subsystem with easter eggs, not as the default mode.
